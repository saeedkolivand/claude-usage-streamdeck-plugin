Each profile is a separate Claude account — a config folder holding a projects directory. Set it per key, so one key can watch work and the next personal. Only ~/.claude and folders beside it are found automatically; if yours lives elsewhere (via CLAUDE_CONFIG_DIR), type the path under Custom folder.
The key alternates the 5-hour and weekly faces every Interval seconds; pressing the key switches immediately (works even with auto-rotate off). Labels and base colors are per key — e.g. 5 HORAS / SEMANAL. The %, bar and countdown tones derive from the base color; past the Amber/Red thresholds the % and bar switch to the alert colors.
Optional. Overrides the key's top title (default Session, Weekly, Tokens, …). Try 5h Session or Woche. Leave blank to keep the metric's name.
Overrides the scope line under the value — e.g. hoje, 7 dias, sessão.
Thresholds color the live limit metrics (Session / Weekly / Carousel). The alert flash fires once when a limit climbs past Red and re-arms after the window resets.
Advanced Leave blank unless requests start failing. Must begin with claude-code/ or the API rate-limits aggressively. Bump the version number if Anthropic tightens the check.
Model weekly is the per-model 7-day limit (e.g. the primary model's own cap) and shows -- on plans that don't report one. Tokens & cost come from Claude Code's local logs; cost is a best-effort estimate (and notional "equivalent API spend" on Pro/Max). Tap a key to force a refresh; otherwise it updates every 60s.
