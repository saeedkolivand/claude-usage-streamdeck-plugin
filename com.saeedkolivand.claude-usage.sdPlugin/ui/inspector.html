Each profile is a separate Claude account — a config folder holding a projects directory. Set it per key, so one key can watch work and the next personal. Only ~/.claude and folders beside it are found automatically; if yours lives elsewhere (via CLAUDE_CONFIG_DIR), type the path under Custom folder.
Appearance — colors for this key Colors for this key only (works on the Stream Deck + touch strip too). Background is the whole tile. Numbers is the big value (the % or token count). Labels is the title and the small text under the value. Accent is the little underline, the chart bars and the icons. Pickers you don't touch keep the built-in look. The Carousel keeps its own face colors (set below) — only Background applies to it. Reset colors to default
Tick the faces this key rotates through and use the arrows to set their order. Starts on then picks which of them the key shows when it loads. The Badge is off by default; tick it and it leads the rotation, like a splash before the numbers. The key alternates the 5-hour and weekly faces every Interval seconds; pressing the key switches immediately (works even with auto-rotate off). Starts on picks the face the key shows when it loads — turn Auto-rotate off (or drag Interval down to never) and it stays there, so two keys side by side can hold one window each. The Badge face is a picture rather than a number — a gauge by default, or any image you point it at — held for its own number of seconds, which overrides the interval. Labels and base colors are per key — e.g. 5 HORAS / SEMANAL. The %, bar and countdown tones derive from the base color; past the Amber/Red thresholds the % and bar switch to the alert colors.
Optional. Overrides the key's top title (default Session, Weekly, Tokens, …). Try 5h Session or Woche. Leave blank to keep the metric's name.
Overrides the scope line under the value — e.g. hoje, 7 dias, sessão.
Thresholds color the live limit metrics (Session / Weekly / Carousel). The alert flash fires once when a limit climbs past Red and re-arms after the window resets.
Advanced Leave blank unless requests start failing. Must begin with claude-code/ or the API rate-limits aggressively. Bump the version number if Anthropic tightens the check.
Model weekly is the per-model 7-day limit (e.g. the primary model's own cap) and shows -- on plans that don't report one. Tokens & cost come from Claude Code's local logs; cost is a best-effort estimate (and notional "equivalent API spend" on Pro/Max). Tap a key to force a refresh; otherwise it updates every 60s.
